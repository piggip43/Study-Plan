4. 依研究主線與現有稿件成熟度暫定第一順位期刊，另外保留兩本備選。

完成證據：3本目標期刊比較表、官方來源連結、第一順位期刊及選擇理由。

### （二）星期三：修訂英文Methods

1. 依第一順位期刊的文章結構重排Methods，但每項內容仍須連回《蔡宏昱論文》第3章、PDF頁碼或表格。
2. 保留研究設計與資料來源、MRI影像角度與序列、標註與前處理及資料增量、分類模型與Stacking、分割模型與Grad-CAM、評估指標與倫理資訊。
3. 刪除只適合學位論文的教科書式背景及重複模型介紹；不刪除重現研究所必需且PDF已提供的資訊。
4. 對患者數、影像數、資料切分、模型參數或倫理資訊的缺漏維持「待作者確認」，不自行補寫或要求重跑分析。

完成證據：英文Methods第一輪修訂稿、期刊要求對照、來源註記及作者確認標記。

### （三）星期五：修訂英文Results

1. 依研究問題安排分類單模型、Stacking、Grad-CAM及分割結果，避免照原論文逐章搬移。
2. 每段先陳述比較問題，再放原論文可支持的主要結果，並連回預定表圖。
3. 將主文只需呈現的核心結果與適合移入補充資料的完整模型比較分開。
4. 對Stacking Accuracy 94.41%與96.99%以及其他前後不一致數值，同時保留原論文位置並標記「待作者確認」，不自行選值或重算。

完成證據：英文Results第一輪修訂稿、結果與表圖對照、主文及補充圖表清單、更新後作者確認清單。

### （四）星期六：期刊排序與稿件整合

1. 回查比較表中的官方規定，確認第一順位及兩本備選的排序，並寫出各期刊的一項優勢與一項風險。
2. 用格式檢查表核對Methods與Results的標題層級、縮寫首次定義、圖表引用及必要聲明位置。
3. 把修訂後Methods、Results、Introduction大綱、Discussion大綱、圖表清單及作者確認清單整合進同一稿件骨架。
4. 列出9月28日至10月4日需要完成的第二輪修訂，不提前定稿Title與Abstract，也不使用尚未確認的矛盾數值。

完成證據：定稿版目標期刊比較表及排序、期刊格式檢查表、整合後英文稿件骨架、下一周修訂清單。
